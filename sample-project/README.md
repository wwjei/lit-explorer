# Sample Project

这是一个用于试用「项目文件浏览器」的示例目录。

## 里面有什么

- `index.html` + `styles.css`：验证 HTML 预览能否加载**相对路径**的样式表
- `docs/`：几个 Markdown 文档
- `src/`：几层嵌套目录，用来试多栏导航
- `assets/logo.svg`：图片预览

## 试试这些操作

1. 在最左栏点击 `src`，再点 `components`，看第三栏展开
2. 点 `index.html`，右侧会显示带地址栏的迷你浏览器
3. 点 `README.md`，右侧显示排版后的正文，可切「源码」
4. 双击任意文件，用系统默认程序打开

> 浏览器的搜索框支持按名称过滤当前已展开的各栏。
