# 使用指南

## 基本操作

| 操作 | 行为 |
| --- | --- |
| 单击文件 | 选中并在右侧预览 |
| 单击文件夹 | 展开下一栏 |
| 双击文件 | 用系统默认程序打开 |
| `↑` `↓` | 当前栏内上下移动 |
| `→` | 进入选中的文件夹 |
| `←` | 回到上一级 |
| `F5` | 重新扫描当前目录 |

## 关于预览

预览按扩展名自动分派：

1. **HTML** —— 在带地址栏的迷你浏览器里渲染，相对路径的样式与脚本都能正常工作
2. **Markdown** —— 渲染成排版正文，可切换源码
3. **代码** —— 行号 + 语法高亮
4. **图片** —— 等比缩放显示

> 二进制文件会显示兜底卡片，并提供「用默认程序打开」。

## 大目录

单栏条目超过 120 个时自动启用虚拟滚动，只渲染可视区域内的行，
所以打开上万个文件的目录也不会卡。
